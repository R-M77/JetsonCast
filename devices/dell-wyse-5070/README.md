# Dell Wyse 5070

**Candidate, not physically tested.** It uses the existing x86-64 build, whose
download/extraction/patch were validated. That is not a playback or Wi-Fi test.

A used unit can be an economical TV computer. Prefer 8GB RAM and at least 64GB
of usable storage as a practical buying target. Check the included power supply,
storage configuration and Wi-Fi: wireless was optional. The slim enclosure is
184 × 184 × 35.6 mm. DisplayPort requires an audio-capable adapter/cable for an
HDMI-only TV. [Dell specifications](https://www.delltechnologies.com/asset/en-ca/products/thin-clients/technical-support/Wyse_5070_executive_summary_and_data_sheet.pdf).

Install a supported 64-bit Ubuntu desktop and verify TV picture and sound first.
From the repository, use `python3 install.py --device mini-pc` and follow the
[mini-PC guide](../mini-pc/). Start with 720p, then test 1080p, wake and a second cast.
Avoid buying solely because the seller advertises 4K display output.
